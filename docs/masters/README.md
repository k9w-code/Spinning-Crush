# マスタデータ仕様書 (Master Data Specifications)

本作『Spinning-Crush』の全マスターデータをMarkdown形式で管理・閲覧するためのドキュメント群です。  
CSV形式のマスター原本（`public/sheets/*.csv`）と1対1で整合しており、GitHub、Notion、Obsidian、スプレッドシート等へのコピー＆ペーストに最適化されています。

## ドキュメント一覧

- [シナリオマスタ.md](./シナリオマスタ.md)
  - プロローグ（全3編）、チュートリアル完了、幕間イベント（全6編）、全31体の戦闘前後シナリオ（全227行）
- [セリフマスタ.md](./セリフマスタ.md)
  - プレイヤーおよび全31体エネミーの戦闘前・勝利・敗北セリフ、全5系統奥義叫び帯テキスト（全254行）
- [奥義マスタ.md](./奥義マスタ.md)
  - 全20種チップの奥義（小奥義・大奥義・防御・回避・カウンター）全80種のデータ・格調高き神話フレーバー
- [チップマスタ.md](./チップマスタ.md)
  - 全20種の聖獣コアチップ、解放奥義ID、世界観フレーバーテキスト
- [ステージマスタ.md](./ステージマスタ.md)
  - 全7ステージの名称、解放条件、ガチャ解禁ランク、アリーナ情景フレーバーテキスト
- [エネミーマスタ.md](./エネミーマスタ.md)
  - 全31体エネミーの装備アセンブル、AI設定、キャラクター造形メモ

## 文字コード規約
- すべてのファイルは **UTF-8 (BOMなし)** で作成・保存されています。
